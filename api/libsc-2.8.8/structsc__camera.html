Detailed Description

Represents a camera with parameters for rendering a 3D scene.

The sc_camera object stores essential properties of a camera, including its position, rotation, field of view, viewport dimensions, and clipping planes. These parameters define how the camera projects the 3D world onto the 2D image plane.
