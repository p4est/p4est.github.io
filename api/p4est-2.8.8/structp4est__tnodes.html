Field Documentation

◆ element_bits

sc_array_t* p4est_tnodes::element_bits

For each local element, one or four bytes of flag bits.

For degree 1, there is one byte per local element storing 2 bits. For degree 2, there are four bytes per local element of this kind. A bit is set if the corresponding elementary simplex exists. Simplices may be omitted at a hanging face.
