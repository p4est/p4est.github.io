Detailed Description

Generate a conforming tetrahedron mesh from a 2:1 balanced p8est.

This mesh is based on a given p8est_lnodes structure. Additional lookup tables define the simplex mesh.

Please see a textual overview under Conforming simplex export.

◆ p8est_tnodes_face_normal

const int p8est_tnodes_face_normal[6]
extern

For every simplex number the normal direction of its outside face.

The normal is for every k = 2i + j, with i in [0, 3), j in [0, 2). The edge direction is i, and j indexes the normals of the two faces touching an edge of this direction in ascending order. The result is a normal direction in [0, 3).

◆ p8est_tnodes_simplex_reverse

const int p8est_tnodes_simplex_reverse[6]

The number of the congruent simplex that starts at the antipode.

There is exactly one simplex that starts at the antipode corner for every one starting at the anchor corner, in reverse order.
