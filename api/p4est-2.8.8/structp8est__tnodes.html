Detailed Description

Lookup table structure defining a conforming tetrahedral mesh.

Field Documentation

◆ element_bits

sc_array_t* p8est_tnodes::element_bits

For each local element, one or eight bytes of flag bits.

For degree 1, there is one byte per local element storing 6 bits. For degree 2, there are eight bytes per local element of this kind. A bit is set if the corresponding elementary simplex exists. Simplices may be omitted at a hanging face or edge.
