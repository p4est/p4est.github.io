Detailed Description

Generate a conforming triangle mesh from a 2:1 balanced p4est.

This mesh is based on a given p4est_lnodes structure. Additional lookup tables define the simplex mesh.

Please see a textual overview under Conforming simplex export.

const int p4est_tnodes_simplex_reverse[2]
extern

The number of the congruent simplex that starts at the antipode.

There is exactly one simplex that starts at the antipode corner for every one starting at the anchor corner, in reverse order.
